删除项目中所有 Notion SDK 集成代码、为 Notion 推送服务的 handlers、以及关联的数据类型定义，同时清理不再需要的依赖项。

## 删除清单

### 目录级删除

- `core/notion/`（整目录，9 个文件）
    - `__init__.py` / `client.py` / `content_builder.py` / `datetime_helper.py`
    - `flow_database.py` / `models.py` / `retry_helper.py` / `stock_pool.py` / `upload_file.py`
- `core/handlers/`（整目录）
    - `__init__.py` / `business.py`
    - `announcements/__init__.py` / `deduplicator.py` / `fetcher.py` / `page_creator.py` / `uploader.py`
- `core/data/`（整目录，handlers 删掉后全为死代码）
    - `__init__.py` / `announcement.py` / `api_models.py` / `business.py` / `exceptions.py` / `models.py`
- `core/models/`（整目录）
    - `__init__.py`（`NotionDate` / `UpdateRecordKey` 随 db repository 函数一并死亡）
    - `announcement.py`（`AnnouncementWithHash`，仅 handlers 使用）
    - `upload.py`（`FileUploadRequest` / `FileUploadWithContent` / `FileUploadResult`，仅 Notion 上传使用）
- `tests/test_notion/`（整目录，目前仅空 `__init__.py`）
- `tests/resource/`（整目录，仅服务于 `test_business_data_handler.py`）
    - `__init__.py` / `fetch_business.py` / `manager.py` / 所有 `.pkl` / `.meta.json` 文件

### 文件级删除

- `scripts/test_pipeline.py`（旧管线测试脚本）
- `core/db/models.py`（`HashRecord` / `UpdateRecord` 均服务于公告推送管线；`Base` 由 PG 迁移任务重建）
- `tests/test_db.py`（测试上述 ORM 模型）
- `tests/test_business_data_handler.py`（全部测试 `core.handlers.business`，随 handlers 删除）

### 文件级部分删除 / 编辑

- `core/db/__init__.py` — 删除所有 repository 函数（`check_hash` / `save_hash` / `get_update_time` / `set_update_time` 及相关 dataclass `HashContent` / `HashContentWithHash`），保留 engine re-exports（`get_engine` / `get_session` / `init_db` 等）
- `tests/conftest.py` — 移除以下内容：
    - `test_engine` / `in_memory_db` fixture（依赖 `core.db.models.Base`，随模型删除）
    - `test_env` 中的 `NOTION_TOKEN` / `FLOW_DATABASE` / `STOCK_POOL` 环境变量读取
    - `pytest_sessionfinish` 中 `core.notion` client 的清理逻辑

### 依赖项删除（`pyproject.toml`）

# 删除以下两行

"aiosqlite==0.22.1",
